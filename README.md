# 🛍️ Loja Digital

Projeto de uma loja digital moderna com slider interativo, inspirado no estilo Apple.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎨 Funcionalidades

- Slider de produtos interativo
- Animações suaves
- Navbar com efeito hover
- Design responsivo
